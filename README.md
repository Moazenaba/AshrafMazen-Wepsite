# موقع الشيخ أشرف مازن

موقع علمي: دروس مرئية وصوتية ومكتوبة، ومكتبة كتب PDF، مع لوحة إدارة كاملة. الواجهة عربية من اليمين لليسار.

- **الواجهة:** React 19 + Vite + Tailwind 4 (صفحة واحدة، وكل صفحة ملف يُحمَّل عند طلبها).
- **قاعدة البيانات وتسجيل دخول الإدارة:** Supabase (Postgres + Auth).
- **تخزين الملفات** (صوت، كتب، أغلفة، لوجو): Cloudflare R2 فقط.
- **السيرفر:** دوال Vercel في مجلد `api/` (تحمل مفاتيح R2 السرية، وتستقبل طلبات الزوار، وتزامن يوتيوب).
- **لا حسابات للزوار.** كل ما يرسله الزائر ينتظر موافقة الإدارة.

> للأعطال وطرق إصلاحها: [`docs/TROUBLESHOOTING.md`](docs/TROUBLESHOOTING.md).
> لمراجعة ما اكتمل وما بقي: [`docs/REVIEW-ME.md`](docs/REVIEW-ME.md).

## تشغيل المشروع محلياً

```bash
npm install
cp .env.example .env.local      # ثم املأ القيم
npm run dev                      # http://localhost:3000
```

السيرفر المحلي يشغّل دوال `api/` أيضاً، فكل شيء يعمل كما على Vercel.

## الأوامر

| الأمر | ما يفعله |
|---|---|
| `npm run dev` | تشغيل الموقع محلياً (مع دوال `api/`) |
| `npm run build` | يولّد `sitemap.xml` و`robots.txt` ثم يبني الموقع في `dist/` |
| `npm run check` | فحص الأنواع ثم البناء: شغّله قبل كل رفع |
| `npm run health` | يفحص القاعدة والصلاحيات وR2 من سطر الأوامر (`-- --write` يضيف اختبار إرسال طلب) |
| `npm run smoke http://localhost:3000` | يفتح كل صفحة ودالة كما يفعل الزائر (يعمل أيضاً على الموقع المنشور) |
| `npm run r2:setup` | يجرّب R2: رفع وقراءة وحذف (وضبط CORS إن سمحت صلاحية التوكن) |
| `npm run sitemap` | يكتب `public/sitemap.xml` يدوياً |
| `npm run sync:youtube` ثم `npm run build:library` | تحديث النسخة المضمّنة من قوائم يوتيوب |

## المتغيرات البيئية

انسخ `.env.example` إلى `.env.local`، وفي Vercel ضع نفس الأسماء في **Settings ← Environment Variables**.

| الاسم | سرّي؟ | الغرض |
|---|---|---|
| `VITE_SUPABASE_URL`, `VITE_SUPABASE_ANON_KEY` | لا (يظهران في الموقع) | اتصال المتصفح بقاعدة البيانات |
| `SUPABASE_URL`, `SUPABASE_ANON_KEY` | لا | نفس القيمتين، تقرؤهما دوال `api/` |
| `R2_ACCOUNT_ID`, `R2_BUCKET` | لا | حساب Cloudflare واسم الحاوية |
| `R2_ACCESS_KEY_ID`, `R2_SECRET_ACCESS_KEY` | **نعم** | مفاتيح R2. للسيرفر فقط، ولا تضع قبلها `VITE_` أبداً |
| `VITE_R2_PUBLIC_URL` | لا | اختياري: عنوان عام للحاوية. اتركه فارغاً لتبقى الحاوية خاصة |
| `SITE_URL` | لا | العنوان العام للموقع، يُستعمل في `sitemap.xml` |

## النشر (مرة واحدة)

1. **Supabase:** شغّل ملفات `docs/migrations/` بالترتيب في SQL Editor ([الترتيب](docs/migrations/README.md)). كلها آمنة عند إعادة التشغيل.
2. **Cloudflare R2:** من الحاوية ← **Settings ← CORS Policy** ← الصق `docs/r2-cors.json` (وأضف دومين الموقع إن اختلف).
3. **Vercel:** استورد المشروع، أضف المتغيرات أعلاه، ثم انشر. الملف `vercel.json` يتولى توجيه الصفحات وتخزين الملفات مؤقتاً.
4. **تحقق:** ادخل لوحة الإدارة ← **البيانات والتكامل** ← يجب أن تكون كل الفحوص خضراء، واضغط «جرّب الرفع الآن».
5. شغّل `npm run smoke https://دومين-الموقع`.

## أين يُحفظ كل شيء

| ما هو | أين | ملاحظة |
|---|---|---|
| الأقسام والسلاسل والدروس | جداول `categories` و`series` و`lessons` | يديرها الأدمن |
| فصول الدرس، واختيار «اخترنا لك» | سجل `lesson_extras` في `site_settings` | |
| الكتب (قائمة) | سجل `library_books` في `site_settings` | الملفات نفسها على R2 |
| إخفاء فيديوهات القناة وتغيير عناوينها | سجل `youtube_overrides` في `site_settings` | |
| اسم الموقع واللوجو ونبذة الشيخ وروابط التواصل | `site_settings` و`social_links` | |
| طلبات الزوار | جدول `submissions` | الزائر يضيف فقط، والأدمن يراجع |
| الإحصائيات | `content_stats` و`daily_stats` و`daily_visitors` و`visitor_pings` | مجهولة الهوية |
| الصوت والكتب والأغلفة واللوجو | Cloudflare R2 | مجلدات: `audio/` و`library/files/` و`library/covers/` و`branding/` |
| فيديوهات القناة | يوتيوب (RSS) + نسخة مضمّنة في `src/data/youtube-library.ts` | تتحدث كل ٦ ساعات من `api/youtube-library.ts` |
| المحفوظات، ومكان التوقف في كل درس | متصفح الزائر نفسه (`localStorage`) | لا تنتقل بين الأجهزة |

## الأمان

- **الزائر** يقرأ المحتوى المنشور فقط. لا يكتب في أي جدول مباشرة؛ يرسل طلباً عبر `api/submit` ينتظر موافقتك.
- **الأدمن** هو من له صف في جدول `admins`. كل صلاحيات الكتابة تتحقق منه داخل قاعدة البيانات (دالة `is_admin()`)، لا في الواجهة فقط.
- **R2:** الحاوية خاصة. الرفع عبر رابط موقّع قصير العمر تعطيه `api/r2` للأدمن فقط. القراءة عبر `api/r2?file=` لمجلدات الموقع فقط.
- **الإحصائيات:** معرّف الزائر رقم عشوائي في متصفحه، بلا بيانات شخصية. الأرقام المجمّعة للأدمن فقط.
- لا تضع مفاتيح سرية في أي متغير يبدأ بـ `VITE_`، ولا في الكود.

## هيكل المشروع

```
api/                 دوال السيرفر (Vercel): r2.ts (الملفات) و submit.ts (طلبات الزوار) و youtube-library.ts
src/
  pages/             صفحات الموقع، وpages/admin للإدارة
  components/        مكونات مشتركة، وcomponents/admin لشاشات الإدارة
  context/           الصوت المستمر (AudioContext) والثيم
  services/          الوصول للبيانات (dataService) والإحصائيات والملفات (r2) والمحفوظات
  lib/               أدوات: يوتيوب، Supabase، قراءة مكتبة الفيديو مع إخفاء الأدمن
  data/              نسخة مضمّنة من قوائم يوتيوب (مولَّدة)
scripts/             أدوات سطر الأوامر: sitemap و health و smoke و r2-setup ومزامنة يوتيوب
docs/                الهجرات (migrations) والإصلاح والمراجعة
```

## لوحة الإدارة (`/admin`)

الإحصائيات · الطلبات · فيديوهات القناة · إدارة الدروس · إدارة السلاسل · إدارة الأقسام · المكتبة · إدارة الواجهة والتواصل · البيانات والتكامل.

رابط الدخول: أيقونة الدخول في الهيدر (وفي قائمة الموبايل «دخول الإدارة»)، أو اكتب `/admin` في العنوان. لا يدخل إلا من له صف في جدول `admins`.
